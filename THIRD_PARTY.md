# Third-party components

Planned/default integrations are independently licensed:

- llama.cpp — local GGUF inference runtime
- Qwen3 1.7B GGUF — local language model, Apache-2.0 distribution
- Whisper-compatible local speech recognition
- Piper/sherpa-onnx compatible local speech synthesis
- Vosk/openWakeWord compatible wake processing
- SearXNG — optional self-hostable metasearch

Model weights and third-party binaries are not stored in this repository unless a future release explicitly documents license and provenance.
