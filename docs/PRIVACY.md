# Privacy

## Offline mode
No research, updates or model downloads occur. Installed chat, memory, knowledge, tools and voice components remain local.

## Connected research mode
The LLM remains local. Only purpose-approved network operations are allowed. Research sends the minimum sanitized public query needed. Private memories, documents, raw transcripts, credentials and profile fields are excluded unless the user explicitly selects content for transmission.

## Storage
User data belongs in the runtime data directory, never the Git repository. Sensitive stores should use OS-appropriate permissions and keyring/encryption support where available.

## Retention
Users must be able to inspect, export and delete memories and researched knowledge. Web knowledge retains provenance and timestamps for refresh/removal.
